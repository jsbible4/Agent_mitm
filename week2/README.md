### payload

1. prompt payload
<img width="867" height="273" alt="p1" src="https://github.com/user-attachments/assets/2ecaa80b-1f71-41e7-b145-95c7b72c328b" />

Key fields

trace_id: Identifies the request flow across multiple HTTP messages

stage: "prompt": Marks this payload as a prompt message

prompt: The input content provided to the agent


2. tool-call payload
<img width="851" height="437" alt="p2" src="https://github.com/user-attachments/assets/ec5865e9-d294-48cc-aa7a-9c8eba385703" />

Key fields

trace_id: Preserves request traceability

stage: "tool-call": Indicates a tool invocation request

tool: The selected tool (read_file)

args: Arguments required to execute the tool (e.g., file path)

3. tool-response payload
<img width="867" height="319" alt="p3" src="https://github.com/user-attachments/assets/23d72064-1781-48b2-af0f-2c177cc0bb60" />

trace_id: Matches the response to the original request

stage: "tool-response": Indicates a tool execution result

status: Execution status (ok)

result: Output produced by the tool (file content)

4. final response payload
<img width="846" height="190" alt="p4" src="https://github.com/user-attachments/assets/af01caaf-95e2-4d32-a480-44ea09c658ed" />

Key fields

trace_id: Maintains end-to-end request correlation

final_response: Human-readable summary of the agent’s processing outcome

text: Final message generated by Agent B
